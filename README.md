# RestauraFisio+

Solução web desenvolvida como projeto de extensão do curso de Análise e Desenvolvimento de Sistemas.

## Objetivo

Desenvolver uma aplicação web para auxiliar na organização e no gerenciamento dos atendimentos de uma clínica de fisioterapia, contribuindo para a digitalização das informações e otimização da rotina.

## Funcionalidades previstas

- Cadastro e gerenciamento de pacientes
- Registro de atendimentos
- Registro e consulta de evoluções
- Controle financeiro básico por sessão
- Relatórios
- Exportação de relatórios em PDF

## Tecnologias previstas

- HTML
- CSS
- JavaScript
- Node.js
- Express
- PostgreSQL
- Git e GitHub
